# Morrow & Moss Storefront

A single-file, responsive storefront demo built with plain HTML, CSS, and JavaScript. No build tools or external JavaScript libraries are required.

## Try it locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser, or serve this folder with any static web server.

## What works

- Browse 12 sample products; filter by category, search, and sort.
- Add products to the bag, adjust quantities, remove items, and see the subtotal update.
- The bag persists in the browser's local storage.
- Submit the demo checkout form to see a sample confirmation.

## Demo limitations

This is a fictional sample storefront. Checkout does not take payment or send an order to a merchant. The contact, social, policy, and newsletter links are placeholders. Product photography is served from Unsplash and requires an internet connection. Product names, prices, and availability are sample content, not a real offer.

## GitHub Pages

This repository is configured to publish from the `main` branch, root folder (`/`). Once the Pages deployment finishes, open the repository's Pages URL.
